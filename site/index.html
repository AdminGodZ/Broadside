Rules

Standard 10×10 board. Fleet: Carrier 5, Battleship 4, Cruiser 3, Submarine 3, Destroyer 2. Ships lie horizontally or vertically, may touch, and may not overlap.

Each shot reports miss, hit, or sunk with the ship's name. A hit alone does not say which ship it struck.

Run it

Unpack, then from the folder:

./broadside play --heat  # you vs the engine
./broadside assist       # it calls your shots
./broadside help         # every command

Windows: broadside.exe play --heat. --heat shows where the engine expects your ships.

Or build it for your own CPU

The downloads target a common baseline so they run everywhere. A build from source uses every instruction your processor has, and is the fastest way to run it:

git clone https://github.com/AdminGodZ/Broadside
cd Broadside
cargo run --release -p broadside -- play --heat

On macOS the binary is not signed by an Apple developer ID, so the first launch is blocked. Allow it under System Settings → Privacy & Security, or run xattr -d com.apple.quarantine broadside. Checksums for every file are in SHA256SUMS.txt on the release page.

How it works

Most Battleship bots estimate where ships might be. Broadside counts every fleet that fits what it has seen, exactly, on every turn.

01 · Exact inference

Every layout, counted

Every layout consistent with the misses, hits and sinking reports is counted exactly: sunk ships enumerated, hits assigned to afloat ships by exact-cover search, untouched ships counted in closed form with popcounts.

02 · Search

Possible worlds, played out

Once the ships afloat have few enough joint placements to list, each placement becomes a possible world. Candidate shots are compared by playing them to the end in every world; small positions are solved outright.

03 · Subtlety

A certain hit is not always right

A cell can be sure to hold a ship while it is unclear which ship. Hitting it changes which later shot announces which sinking, and that can cost information. The search decides.

04 · Placement

Hard to hunt

Fleets are placed from an equilibrium mix of tilted layouts, computed from the placement game, so even a shooter that expects the tilt cannot exploit it.

05 · Learning

It learns your habits

Across a match the shooter learns where you place ships, and the placer learns where you search last. Both learn only from what a real game shows.

06 · Spacing

Apart, cornered or stacked

Some players never let ships touch, some stack them. The engine counts each kind of layout exactly and holds a belief over them that starts neutral and can't be milked by an opponent who plays against it.

Head to head against a human-style player

The parity bot hunts on a checkerboard and finishes ships around its hits, much like a careful human. Over 10,000 games Broadside won 70.8%. Single games are close to a coin flip with a thumb on it; matches are not.
